These original synthesized WAV assets are bundled locally and require no network access.

- `space.wav`: 16-second ambient chord (C3, E3, G3, C4).
- `night.wav`: 16-second ambient chord (A2, C3, E3, A3).
- `star.wav`: short two-tone confirmation sound.

All files use mono 16-bit PCM at 22,050 Hz. Ambient tracks fade in and out for looping.
