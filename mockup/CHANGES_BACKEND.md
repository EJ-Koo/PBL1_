# Backend 변경 기록

목업(`mockup/`) 통합 작업 중 백엔드 코드(`backend/`) 자체를 수정한 내역을 기록하는 문서.

---

## 2026-09-29

**변경 없음.** 이번 통합 작업은 프론트(`mockup/`)만 건드렸고, `backend/` 코드는 손대지 않음
(로그인 연동은 팀원이 `back_end_wodnjs` 브랜치에서 이미 구현해놓은 백엔드를 그대로 사용).

## 확인된, 아직 처리 안 된 백엔드 쪽 이슈
- 일기 **수정(PUT)** 엔드포인트가 없음 — `backend/app/routers/diaries.py`엔 `GET`(목록/단건),
  `POST`(생성)만 있고 수정/삭제가 없음. 프론트 `write.tsx`엔 이미 수정 UI가 있어서, 이 API가
  생기면 바로 연결 가능한 상태.
- (참고용) 일기 생성/조회 프론트 연동은 다음 작업 예정 — 이건 백엔드 API가 이미 있어서
  백엔드 수정 없이 프론트만 작업하면 됨.
