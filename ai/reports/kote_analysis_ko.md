## 2. 구조와 정답 형식

| 분할 | 행 수 | 컬럼 |
|---|---:|---|
| train | 40,000 | `ID`(str), `text`(str), `labels`(str, 예: `"2,13,15"`) |
| validation | 5,000 | 〃 |
| test | 5,000 | 〃 |
| **합계** | **50,000** | |

- `ID`: `"0"`~`"49999"` 숫자 문자열, 전부 고유, 분할 사이 겹침 없음. 세 분할이 ID 범위 전체에 퍼져 있다(무작위 분할).
- `labels`: 공백 없는 쉼표 구분 정수, 모든 행이 오름차순, 관측 범위 0–43(44개 모두 등장).
- 라벨 44개 = 감정 43 + ‘없음’(ID 24). 공식 `kote.py`의 `_LABELS` 및 Parquet ClassLabel과 순서까지 같으며 `ai/configs/kote_labels.json`에 저장했다.

## 3. 원시 주석과 배포 라벨의 관계

| 항목 | 값 |
|---|---:|
| 댓글 수 | 50,000 |
| 댓글당 평가자 수 | 5 (모든 댓글) |
| 원시 주석 수 (댓글 × 평가자) | 250,000 |
| 라벨 선택 총횟수 | 808,735 (주석 1건당 평균 3.235개) |
| ‘없음’만 고른 주석 | 11,821 |
| ‘없음’과 다른 감정을 함께 고른 주석 | 99 |
| 빈 주석 / 목록 밖 라벨명 / 평가자 내 중복 | 0 / 0 / 0 |

**공식 집계 기준**(논문 4.2·4.4절): 5명의 선택을 합해 라벨별 0–5 값을 만들고, 댓글별 min-max 스케일링 후 **0.2를 초과하면 1**로 둔다.
이 규칙을 `raw.json`에 그대로 적용하면 **배포 라벨 50,000/50,000건이 정확히 재현된다.**

모든 댓글에서 최소 선택 인원이 0이므로, 실제로는 `선택 인원 / 그 댓글의 최대 선택 인원 > 0.2`와 같다.

| 선택 인원 | (댓글, 라벨) 칸 수 | 배포 라벨 양성 비율 |
|---:|---:|---:|
| 0 | 1,759,497 | 0% |
| 1 | 235,349 | 80.87% |
| 2–5 | 205,154 | 100% |

최대 선택 인원이 5인 댓글(11,760개)에서만 1명 선택이 음성이 된다. 결국 배포 라벨은 ‘가능성 있는 감정’을 넓게 포함하는 **관대한 라벨**이다.

## 5. 감정 라벨 분포

다중 라벨이므로 라벨별 양성 비율의 합(train 7.911 = 791%)은 100%를 넘으며, 샘플당 평균 라벨 수와 같다.

| | train | validation | test |
|---|---:|---:|---:|
| 샘플당 라벨 수 평균 | 7.91 | 7.87 | 7.93 |
| 중앙값 (최소–최대) | 8 (1–22) | 8 (1–21) | 8 (1–19) |

- **빈발 (train)**: 안타까움/실망 43.7%, 불평/불만 41.7%, 어이없음 40.0%, 짜증 37.3%, 화남/분노 30.7%, 한심함 30.5%, 의심/불신 28.9%, 기대감 28.0%, 즐거움/신남 27.2%, 감동/감탄 26.9%
- **희소 (train)**: 죄책감 1.7%(698건), 공포/무서움 3.0%, 패배/자기혐오 4.0%, 서러움 5.1%, 부끄러움 5.8%, 귀찮음 6.1%, 비장함 8.4%
- 양성 비율 1% 미만인 라벨은 없다. 최대/최소 비율 차이는 약 25배이다. 죄책감은 validation 89건, test 84건뿐이다.
- **분할 간 차이**: train 대비 최대 |Δ| 1.71%p(validation, 즐거움/신남), 1.87%p(test, 의심/불신). 평균 |Δ|는 0.47%p / 0.49%p, 비율 배수는 0.90–1.10이다. 분할 간 분포가 고르다.
- **‘없음’**: 양성 비율 15.9% / 15.4% / 14.5%. ‘없음’ 샘플의 98.7%(train 6,261/6,344)는 다른 감정과 함께 붙고, ‘없음’ 단독은 train 83건이다. 따라서 상호배타적 중립 클래스가 아니다. 빈 라벨 샘플은 0건이다.

## 6. 텍스트 길이

| 지표 | 평균 | 중앙값 | p90 | p95 | p99 | 최대 |
|---|---:|---:|---:|---:|---:|---:|
| 문자 수 (전체) | 57.3 | 42 | 115 | 139 | 237 | 404 |
| 토큰 수 (v2021, 특수 토큰 포함) | 27.9 | 21 | 53 | 65 | 108 | 237 |
| 토큰 수 (v2022, 비교) | 27.1 | 21 | 51 | 63 | 104 | 233 |

| max_length | 잘리는 샘플 (v2021) | 비율 | train / validation / test |
|---:|---:|---:|---|
| 128 | 172 | 0.344% | 144 / 13 / 15 |
| 256 | 0 | 0% | 0 / 0 / 0 |
| 512 | 0 | 0% | 0 / 0 / 0 |

- truncation 없이, `[CLS]`·`[SEP]`을 포함해 측정했다. 앞 500개 샘플에서 `[CLS]`/`[SEP]` 위치를 확인했고 `[UNK]` 포함 비율은 0.2%였다.
- `KcELECTRA-base`의 `main` revision(2023 BBPE)은 `add_special_tokens=True`에도 `[CLS]/[SEP]`가 붙지 않아 측정에서 제외했다.

**첫 학습 권장 입력 길이: `max_length=256` + 동적 패딩**
- 잘리는 샘플이 0건이다(최대 237토큰).
- 중앙값이 21토큰이라 동적 패딩이면 대부분의 배치가 짧고, 연산량은 128과 거의 같다.
- 고정 패딩이 필요하면 128도 가능하다(0.34%가 잘림). 512는 이 데이터에서는 이득이 없다.
- KOTE는 짧은 댓글이다. 실제 일기는 더 길 수 있으므로 추론 길이 정책은 일기 길이를 확인한 뒤 따로 정해야 한다.

## 7. 감정 공존 (train)

- 946쌍 모두 한 번 이상 함께 등장하고, 891쌍은 공동 출현 100건 이상이다(샘플당 라벨 약 8개).
- 원시 공동 출현 수 상위: 불평/불만–짜증 12,822, 불평/불만–안타까움/실망 11,797, 불평/불만–어이없음 11,319. 빈발 라벨끼리라 수가 큰 것이므로 관련성 지표로 쓰지 않는다.
- Jaccard 상위(공동 출현 ≥ 100): 불평/불만–짜증 0.68, 화남/분노–짜증 0.62, 행복–기쁨 0.59, 불평/불만–화남/분노 0.58, 즐거움/신남–기쁨 0.57.
- lift 상위(공동 출현 ≥ 100): 패배/자기혐오–죄책감 8.6, 패배/자기혐오–서러움 6.2, 부끄러움–죄책감 5.8, 슬픔–서러움 5.7. 희소 라벨은 lift가 커지기 쉬우므로 ‘슬픔·자기비난 묶음’ 정도로만 해석한다.
- 반대 극성 쌍은 거의 함께 나오지 않는다: 화남/분노–행복, 증오/혐오–행복의 lift는 0.07이다.
- 비판·부정 블록과 긍정 블록이 뚜렷해 라벨 사이에 중복 정보가 많다. 다만 공존은 관대한 집계 규칙의 영향을 받으므로 의미 관계로 단정하지 않는다.

## 10. 해결·결정이 필요한 사항

1. **라벨이 관대하다**: 1명만 골라도 양성인 경우가 많다(1명 선택 칸의 80.9%). 이진 라벨만 쓸지, `raw.json`의 선택 인원을 soft label이나 가중치로 쓸지 정해야 한다. 공식 평가와 비교하려면 배포 이진 라벨로 학습한 베이스라인이 먼저 필요하다.
2. **‘없음’ 처리**: 단독 중립 클래스가 아니므로 44개 독립 출력 중 하나로 둔다. 행성 외형에서 ‘없음’을 어떻게 표현할지 기획과 맞춰야 한다.
3. **라벨 불균형**: 최대/최소 약 25배. macro-F1과 라벨별 F1을 함께 보고, 라벨별 threshold를 validation에서 조정한다.
4. **분할 사이 근접 중복 1쌍**: 공식 분할을 유지하고 기록만 한다(평가 영향 미미).
5. **앞뒤 공백 735건, HTML 엔티티 4건, 제어문자 1건**: 모델 입력 단계에서 정리한다.
6. **도메인 차이**: KOTE는 짧은 온라인 댓글(중앙값 42자)이라 일기 문체·길이와 다를 수 있다. 실제 일기 표본(동의를 받은 데이터)으로 길이와 성능을 확인해야 한다.
